# 面向复杂文档解析的 OCR 与视觉语言模型协同实践

本项目是一次专业实践项目，目标是构建一个面向复杂文档的结构化解析与问答系统。项目尝试比较纯 OCR、纯视觉语言模型（VLM）以及 OCR+VLM 混合式流程在复杂文档理解任务中的差异，并实现一个可视化 Demo。

## 项目背景

复杂文档通常包含正文、标题、表格、图片、公式、图表和多栏排版。传统 OCR 能够较稳定地识别文字并返回坐标，但对图表、图片语义和复杂版面理解能力有限。视觉语言模型具备更强的视觉语义理解能力，但在多页文档、稳定结构化输出和证据定位方面仍存在挑战。

因此，本项目尝试将 OCR 的文本识别与坐标定位能力，与 VLM 的视觉语义理解能力结合起来，构建一个混合式文档理解流程。

## 实践目标

- 实现 PDF/图片文档的页面预处理；
- 实现 OCR/版面解析，获得文本、区域和坐标；
- 调用 VLM 对表格、图表、图片等复杂区域进行理解；
- 将 OCR 文本与 VLM 区域解释整合为 Markdown/JSON；
- 支持简单文档问答与证据区域定位；
- 通过可视化界面对比纯 OCR、纯 VLM 和 OCR+VLM 混合流程的效果。

## 技术路线

```text
PDF / 图片
→ 页面图像化
→ OCR / 版面分析
→ 区域裁剪
→ VLM 局部理解
→ LLM 结构化整合
→ Markdown / JSON 输出
→ 文档问答与证据定位
→ Web 可视化展示


对比方案
OCR-only：仅使用 OCR/版面解析结果进行结构化与问答。
VLM-only：直接将页面图像输入视觉语言模型进行理解。
Hybrid：结合 OCR 的文本与坐标信息，以及 VLM 的视觉语义理解能力。
